# ¿Què hace el proyecto?
    El proyecto es para manejar un iventario, registrando productos, consultandolo en el navegador y guardandolo en la base de datos

# ¿Què tecnologia utiliza?
    PHP version 8.3.16 o superior
    CSS3
    HTML5

# ¿Què se necesita instalar?
    Se necesita PHP,Visual studio code u otro editor de texto, MariaDB que ya contiene MySQL y en conjunto usando la herramienta HeidiSQL, Laragon o XAMPP para levantar el servidor local

# ¿Còmo se configura e instala?
    Primero se descomprime el proyecto luego se tiene que instalar los requerimientos necesarios ya mencionados, luego con el laragon o XAMPP correrlo, encendemos los servicios MySQL y APACHE, para ver la pagina web en el navegador http://inventario.test/ o http://localhost:8080
